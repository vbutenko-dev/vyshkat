# ADR-0004: построчное консольное меню

Дата: 2026-10-25.
Статус: принято.

## Контекст

Задание требует консольное приложение с понятным вводом.
Названия объектов могут содержать пробелы.
Сквозные сценарии нужно воспроизводить без ручного ввода при каждом запуске тестов.

## Решение

Использовать меню с числовыми командами и отдельной строкой для каждого ответа.
Консоль принимает `io.Reader` и `io.Writer` через конструктор.
В `main` передаются стандартные потоки, в тестах — строка и буфер.

Неверный формат числа повторяет поле.
Ошибка заполненной карточки выводится перед возвратом в меню.
Конец ввода завершает работу без частичного добавления.
Ошибка чтения возвращается в точку входа с исходной причиной.

## Альтернативы

- Аргументы командной строки потребовали бы отдельного протокола нескольких операций в одном процессе.
- Чтение отдельных слов разбивало бы названия с пробелами.
- Полноэкранный интерфейс добавил бы сложность вне задачи учёта.

## Последствия

Сценарий можно передать перенаправлением из текстового файла.
Тесты проверяют и текст ответа, и состояние парка.
Добавление нового вида требует дополнения меню выбора конструкторов.
Консоль вызывает сервисы и не повторяет правила техосмотра или отчётов.
